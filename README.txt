MIRACSOFT — Web sitesi

Bu paket güncel portföyü, görselleri, Türkçe/Almanca/İngilizce metinleri ve uygulama indirme dosyalarını içerir. Vira, UstaX ve CookieCup IPA indirmeleri pakete dahildir.

Yerelde çalıştırma
1. ZIP dosyasını çıkarın.
2. MIRACSOFT klasöründe Terminal açın.
3. Şu komutu çalıştırın: python3 -m http.server 8000
4. Tarayıcıda http://localhost:8000 adresini açın.

İndirmelerin çalışması için siteyi bu yerel sunucu üzerinden açın.

Yayınlama
index.html, assets ve downloads klasörlerini statik web barındırma hizmetinize yükleyebilirsiniz. Framework kurulumu veya derleme gerekmez.

Kaynak kodu bağlantıları GitHub depolarının main dalına yönlenir. Açık/koyu tema ve dil tercihleri tarayıcıda saklanır.
